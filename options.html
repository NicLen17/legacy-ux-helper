Legacy UX Helper

Configuración 100% local. No se guardan dominios, URLs ni historial de navegación. Solo preferencias de resaltado en tu navegador.

Almacenamiento: chrome.storage.local · Permisos mínimos: storage, activeTab y scripting

Configuración general

Modo de resaltado
Presets de accesibilidad i Aplican de golpe una paleta de colores pensada para contraste, daltonismo o pantallas tipo ERP. Podés seguir ajustando cada color después.
Colores por tipo de elemento i Cada tipo de control usa un color distinto en el contorno y el glow. Así identificás más rápido botones, enlaces, campos y acciones legacy.
Funciones rápidas
Modo entrenamiento i Muestra una etiqueta con el tipo de cada elemento detectado (Botón, Enlace, etc.) para aprender la interfaz.
Indicador flotante i Chip en la esquina inferior que confirma que el helper está activo y muestra el modo en uso.
Estilo visual
i Define cómo se dibuja el contorno alrededor del elemento: punteado, sólido o con puntos.
i Ancho del contorno en píxeles. Un valor más alto se ve más fácil, pero puede tapar texto chico. 2px
i Distancia entre el elemento y su contorno. Ayuda a que el resaltado no se pegue al borde del control. 2px
i Qué tan visible es la sombra de color alrededor del elemento. 0% es sutil; 100% es muy marcado. 40%
Activar glow (sombra) i Enciende o apaga la sombra de color. El contorno sigue visible aunque desactives el glow.
Rendimiento
Escanear Shadow DOM i Incluye elementos dentro de web components. Desactivalo si la página se pone lenta.
Solo viewport visible i Analiza únicamente lo que está en pantalla. Mejora el rendimiento en listados o grillas muy largas.
Pausar si pestaña oculta i Deja de escanear cuando cambiás de pestaña para ahorrar CPU. Se reanuda al volver.
Selectores CSS
i Selectores CSS de elementos que no querés resaltar: menús, iconos decorativos o zonas que generan ruido.
i Selectores extra para marcar elementos que el detector no reconoce. Se aplican en cualquier sitio; no se guarda el dominio visitado.
Exportar / Importar i Genera una copia JSON de tu configuración en tu equipo, o restaurá una previa. Nada se sube a un servidor.
